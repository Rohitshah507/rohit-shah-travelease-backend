# TravelEase – Smart Tourism System

TravelEase is a modern web-based tourism management system designed to simplify the process of exploring destinations, booking tour packages, and managing travel activities. The platform connects tourists with guides and administrators in a structured and user-friendly environment.

The system provides features such as destination exploration, tour package booking, secure payment integration (khalti), and review systems. It aims to enhance user experience while improving coordination between tourists and guides through a centralized digital platform.

# Tourist Features

- User Registration and Login Authentication
- Browse and Explore Destinations
- View Places and Travel Information
- View Tour Packages with Details
- Filter Packages by Price, Duration, and Destination
- Book Tour Packages
- Secure Payment Integration (khalti)
- View Booking History (My Bookings)
- Submit Reviews and Ratings for Completed Tours
- View AI-Generated Package Descriptions

# Guide Features

- Guide Registration and Login
- Create Tour Packages
- Update and Delete Packages
- Manage Booking Requests
- Confirm or Reject Bookings
- View Tour History
- View Total Earnings Dashboard
- View Ratings and Reviews from Tourists

# Admin Features

- Admin Login and Dashboard Access
- Manage Users (Tourists & Guides)
- Approve or Manage Guide Accounts
- Manage Tour Packages
- Monitor Bookings and Payments
- System-wide Data Management
